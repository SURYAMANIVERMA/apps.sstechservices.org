# SS TECH SERVICES — Apps

TanStack Start application with Supabase authentication/data and Resend-backed queued email processing.

## Start locally

1. Copy `.env.example` to `.env` and fill in the correct values.
2. Run `npm install`.
3. Run `npm run dev`.
4. Run `npm run build` to create the production build.

## Deployment

Read [DEPLOYMENT-NOTES.md](./DEPLOYMENT-NOTES.md) before deploying. This application has server routes and must run on a server-capable platform such as Cloudflare Workers; it is not a static-only GitHub Pages application.
